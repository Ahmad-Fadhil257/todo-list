# Taskly - Premium Todo List

A simple, modern, and premium Todo List application built with React and Vite.

## Features
- **Modern UI**: Dark mode with glassmorphism aesthetics.
- **Local Persistence**: Uses LocalStorage to save your tasks.
- **Filtering**: Filter tasks by All, Active, and Completed.
- **Micro-animations**: Smooth transitions for adding and deleting tasks.

## Tech Stack
- **Frontend**: React + Vite
- **Styling**: Vanilla CSS (Premium Custom Styles)

## How to Run
1. Clone the repository.
2. Run `pnpm install` or `npm install`.
3. Run `pnpm dev` or `npm run dev`.
